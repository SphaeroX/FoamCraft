A wind tunnel on your desk.

FoamCraft is a free desktop app that runs OpenFOAM flow simulations for people who are not simulation experts. Load a 3D model, press Run, and watch the air move around it or through it.

Get the source on GitHub Watch the demo

In development. No installer yet; you can build it from source.

See it in 20 seconds

From model to result

  1. Bring a model

    STL, OBJ, 3MF, STEP or IGES. FoamCraft checks that it is closed and lets you place it with handles.

  2. Say how the air flows

    Around the part in a virtual wind tunnel, or through it: click a face to make it an inlet or an outlet.

  3. Press Run

    Mesh, solver settings and the stop criterion are chosen for you and sized to your computer.

  4. Look and measure

    Drag, lift, pressure loss and flow per opening, each explained in plain words, plus a light that says how far to trust them.

Build it

You need Rust, Node.js 22 with npm, Docker and a GPU with Vulkan, DirectX 12 or Metal. Windows is the main platform; Linux and macOS work too. 

git clone https://github.com/SphaeroX/FoamCraft
cd FoamCraft
npm ci
cargo build --release -p foamcraft-cli
target/release/foamcraft runtime build
npm run app:dev

On the first start a setup assistant checks Docker, memory and the runtime image. Details are in the README.
